# vscolors.nvim

Port of the Visual Studio theme for neovim.

The plugin provides a single colorscheme `visual-studio-auto` that adapts automatically to the background option.

Add "casimir/vscolors.nvim" to your plugin manager and add the following line to your `init.lua`.

```vim
colorscheme visual-studio-auto
```

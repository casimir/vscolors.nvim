# vscolors.nvim

Port of the Visual Studio theme for neovim.

The plugin provide a single colorscheme `visual-studio-auto` that adapt automatically to the background option.

Colors come from [Visual Studio Light/Dark themes](https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults/themes).

The minimal approach and generic philosophy are inspired by [papercolor-theme-slim](https://github.com/pappasam/papercolor-theme-slim).
